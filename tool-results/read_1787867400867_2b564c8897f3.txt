  4664→## Task 59-A — Light mode visibility fix (globals.css only)

  4668→### Problem
  4669→User reported "I almost didn't see anything and light mode is hurting my eyes." Root causes
  4670→identified in the existing `.light` override block:
  4671→1. CSS variables used pure-white `oklch(0.97 0 0)` background — harsh on the eyes
  4672→2. `text-foreground/N` opacity utilities (15/30/40/50/60/70/75/80/85/90/95) mapped to
  4673→   light grays that were nearly invisible on the near-white background

  4675→   from the page background (e.g. `bg-card/40` ≈ 92% white on 97% white = invisible)
  4676→4. Bright accent hex colors (#FF4500, #00FF94, #00E5FF, #C6FF00, #FF2D7E, #FFB300,
  4677→   #B388FF, #FFEB3B, #2979FF) were barely darkened — most failed WCAG AA 4.5:1

  4679→   `text-muted-foreground/50`, etc.) had NO `.light` override at all

  4681→   the codebase) bypassed Tailwind utility classes entirely
  4682→7. `.sigma-grid`, `.sigma-hazard`, `.sigma-glitch`, `.sigma-vignette` used white-on-dark
  4683→   color schemes that became invisible in light mode
