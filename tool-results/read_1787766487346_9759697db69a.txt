     4→Building "Taungoo Sigma Lab" — a maximalist, awwwards-style Tech Lab website.
     5→- 11 sections, each acts as an absolute full-page view (no nav bar, no scroll)
     6→- Navigation ONLY via a MAP hub (video-game level select with 11 nodes + screenshots)

     9→- Design language: "Sigma Brutalism" — fusion of brutalist cyberpunk (black/white/scanlines) + Helsinki orange editorial + maximalist data HUD

  1029→Task ID: CRON-ROUND-16 (Black Screen Root Cause Fix)
  1030→Agent: main (orchestrator)
  1031→Task: User reported black screen — take seriously, find root cause
  1032→
  1033→## Root Cause
  1034→The `div.fixed.inset-0` root container had `position: fixed` + `inset: 0` (top/right/bottom/left: 0) but **height was computing to 0px**. This is because Tailwind's `inset-0` sets `top:0;right:0;bottom:0;left:0` but on a `fixed` element with no explicit width/height, some browsers compute the height as 0 when the parent chain doesn't establish a proper containing block.
  1035→
  1036→The result: the root container was 1280×0px — everything inside it (map, sectors, all content) was technically "visible" but had 0 height, rendering as a black screen. Only the fixed-position HUD elements (header, footer, sidebars) which don't depend on the parent's height were visible.
  1037→
  1038→## Fix
  1039→Added a CSS rule in `globals.css`:
  1040→```css
  1041→.fixed.inset-0 {
  1042→  width: 100vw;
  1043→  height: 100vh;
  1044→}
  1045→```
  1046→This forces any `fixed.inset-0` element to fill the viewport, regardless of parent height.
